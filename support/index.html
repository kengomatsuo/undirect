Common problems

Undirect does not appear in Safari

Open the app once, then look under Safari Settings, Extensions on Mac, or Settings, Apps, Safari, Extensions on iPhone and iPad.

The rules list is empty

It fills the first time a page tries something. A quiet list means nothing has been caught yet.

A site stopped working after a rule was set

Open the extension button, find the host, and choose Use Default. That removes the rule.

Rules cannot be changed on iPhone or iPad

The list there is read only, because iOS gives an app no way to send changes to its own extension. Changes are made in the extension button in Safari.

A legitimate window was blocked

The host appears in the list. Allow it on that site, or everywhere.
