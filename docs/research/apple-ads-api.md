# Apple Ads spend in Monholt HQ (card ASG184)

Fetched 2026-11-23. Saved copies of every source are in `/Users/hafang/Repositories/undirect/docs/research/apple-ads-api-sources/`.

## Answer

HQ cannot read Apple Ads Basic spend, installs or cost per install from any API or scheduled export. Apple says so in its own help. Only Advanced campaigns can be read, through the Apple Ads Platform API, and that API is free.

Nearest free ways for HQ to show Cutling's Apple Ads spend:

1. Free and automatic, but a different campaign: open a free Advanced account, run Cutling there (with Maximize Conversions, the closest thing to Basic), and let an HQ Worker cron pull daily spend, taps and installs per app into D1. Costs nothing to open, no minimum spend. It bids per tap, not per install (details below).
2. Free and manual, keeps Basic: once a month the owner signs in at app-ads.apple.com (Basic), clicks "Results by countries and regions" and saves the CSV; HQ takes that file on an upload button. Whether the CSV has one row per day is UNSURE (needs his sign-in; Apple's page only says results across all promotions and countries for the chosen period: this month, last month, last three months).
3. Free, no extra work for spend only: Basic invoices (issued about every $500 or 7 days) list per app, per region, per period: installs and spend. Not daily.

Per-day spend per app is only possible with option 1. Options 2 and 3 give period totals.

## What this means for HQ

- Local check already on this machine: `asc ads` (Apple Ads Platform API client, `asc ads api request --method GET --path v1/me`) exists. It will only work with Advanced credentials, so it cannot read Cutling's Basic campaign either.
- Free Advanced route, in HQ terms: one Worker secret set (clientId, teamId, keyId, private key), cron once a day mints the JWT with WebCrypto ES256, posts the DAILY campaign report for the last 7 days, upserts rows (date, app id, spend, currency, impressions, taps, installs) into D1. Cloudflare Worker, cron and D1 free tiers are already what HQ uses; Apple charges nothing for the API. Calendar item: remake the client secret before 180 days.
- Cost of that route is not the API but the campaign: per-tap bidding (a tap that does not install is still paid), a Maximize Conversions target CPA instead of a max CPI, the Basic promotion paused so spend is not doubled, and the 2026-11-16 Basic campaign's history staying only in the Basic dashboard. Whether Maximize Conversions performs like Basic for Cutling is not known; no source I read measures it.
- Spend and installs for already-run Basic periods (Undirect from 2026-11-09, Cutling from 2026-11-16) exist only as the dashboard, CSV and invoices.
- UNSURE and needing the owner's sign-in: whether the Basic CSV has a date column or only totals per country for the chosen period. One click answers it; if it has days, option 2 gives per-day spend free.
