## Guides

### Integration Guides

- [Integration Guide](https://docs.dodopayments.com/developer-resources/integration-guide.md): Create checkout sessions, payment links, and webhooks to accept payments with Dodo Payments. Start with an SDK or REST API.
- [Subscription Integration Guide](https://docs.dodopayments.com/developer-resources/subscription-integration-guide.md): Dodo Payments subscriptions let you charge customers on a recurring schedule. Create subscriptions through checkout sessions, handle webhooks, change plans with proration, and recover failed renewals.
- [Handle Payment Failures](https://docs.dodopayments.com/developer-resources/handle-payment-failures.md): Read failure reasons from the payment object, decide whether to retry, and recover payments safely without exposing sensitive information to customers.
- [Usage-Based Billing Integration Guide](https://docs.dodopayments.com/developer-resources/usage-based-billing-guide.md): Learn how to set up meters and send usage events to enable accurate usage-based billing with Dodo Payments.
- [Manual License Key Fulfillment Integration Guide](https://docs.dodopayments.com/developer-resources/manual-license-key-fulfillment.md): Sell a product whose license keys you supply yourself: create a manual-mode License Key entitlement, detect pending grants, and deliver each key to the customer.
- [Checkout Sessions](https://docs.dodopayments.com/developer-resources/checkout-session.md): Create secure, hosted checkout experiences for one-time payments and subscriptions with full customization control.
- [Dynamic Pricing Checkout with Pay What You Want](https://docs.dodopayments.com/developer-resources/dynamic-pricing-checkout.md): Create checkout sessions with variable pricing using Pay What You Want. Set a minimum price, pass dynamic amounts via API, or let customers choose their price.
- [Subscription Upgrade & Downgrade Guide](https://docs.dodopayments.com/developer-resources/subscription-upgrade-downgrade.md): Learn how to change a customer's subscription plan, handle proration, and process webhooks reliably.

### Billing Deconstructions

- [Billing Deconstructions](https://docs.dodopayments.com/developer-resources/billing-deconstructions/introduction.md): Study how six AI companies charge their users, then rebuild each billing model with Dodo Payments credits, meters, and subscriptions.
- [OpenAI Billing Model](https://docs.dodopayments.com/developer-resources/billing-deconstructions/openai.md): Deconstruct OpenAI's token-based billing with prepaid fiat credits, then rebuild it with Dodo Payments credit entitlements, usage meters, and rate tiers.
- [Cursor Billing Model](https://docs.dodopayments.com/developer-resources/billing-deconstructions/cursor.md): Deconstruct Cursor's model-weighted credit system and build the same hybrid subscription-plus-credits model using Dodo Payments.
- [ElevenLabs Billing Model](https://docs.dodopayments.com/developer-resources/billing-deconstructions/elevenlabs.md): Deconstruct ElevenLabs' character-based billing with rollover credits and tiered overage pricing, then build the same model using Dodo Payments.
- [Midjourney Billing Model](https://docs.dodopayments.com/developer-resources/billing-deconstructions/midjourney.md): Deconstruct Midjourney's GPU-time subscription with Relax Mode fallback and build the same model using Dodo Payments.
- [Replicate Billing Model](https://docs.dodopayments.com/developer-resources/billing-deconstructions/replicate.md): Deconstruct Replicate's per-second hardware-specific billing and build the same pure usage-based model using Dodo Payments.
- [Lovable Billing Model](https://docs.dodopayments.com/developer-resources/billing-deconstructions/lovable.md): Deconstruct Lovable's message-credit subscription with daily bonus drip, team-wide sharing, and separate cloud metering, then build the same model using Dodo Payments.

### Cookbooks

- [Build an AI Image Generator with Usage-Based Billing](https://docs.dodopayments.com/developer-resources/usage-based-billing-build-ai-image-generator.md): Build PixelGen AI, a terminal-based AI image generator that sends a usage event for each image and bills customers per image with Dodo Payments.
- [Seat-Based Pricing with Add-ons and Payment Links](https://docs.dodopayments.com/developer-resources/seat-based-pricing.md): Learn how to create add-ons for seat-based pricing and generate payment links with custom add-on quantities using Dodo Payments
- [Build an AI Chat App with AI SDK & LLM Blueprint](https://docs.dodopayments.com/developer-resources/build-an-ai-chat-app-with-usage-based-billing.md): Build an AI chat app with the AI SDK and Google Gemini. The LLM Blueprint tracks token usage, and Dodo Payments bills customers for the tokens they use.
- [Build an AI API Platform with Credit-Based Billing](https://docs.dodopayments.com/developer-resources/build-an-ai-api-platform-with-credit-based-billing.md): Build NeuralAPI, a tiered AI API with token credits. Subscription plans and top-up packs grant credits, and a meter deducts them as customers call your API.
- [Build a Prepaid Email Service with Credit-Based Billing](https://docs.dodopayments.com/developer-resources/build-a-prepaid-email-service-with-credit-based-billing.md): Build MailKit, a prepaid transactional email service with Dodo Payments and Resend: a monthly credit plan, top-up packs, a debit per send, and low-balance alerts.

## Apps & Connections

### Overview

- [Apps & Connections](https://docs.dodopayments.com/integrations/introduction.md): Connect Dodo Payments to the tools that you use. Install an official app from the Apps page, or send webhook events to a tool with a webhook connector.

### App Marketplace

- [App Marketplace Overview](https://docs.dodopayments.com/features/app-marketplace/overview.md): Find apps that connect Dodo Payments to the tools you use. Learn about official and third-party apps, test mode and live mode, and the permissions that an app can get.
- [Find and Install an App](https://docs.dodopayments.com/features/app-marketplace/find-and-install.md): Search the Explore tab, read the app page, approve the permissions on the consent screen, and install an app in test mode or live mode.
- [Connect and Configure an App](https://docs.dodopayments.com/features/app-marketplace/connect-and-configure.md): Connect your account in a tool with OAuth or API credentials, check the credential test result, and set the options of an installed app on its Configure tab.
- [Manage and Uninstall Apps](https://docs.dodopayments.com/features/app-marketplace/manage-and-uninstall.md): Review the permissions of an installed app, approve new permissions, disconnect or uninstall an app, learn what happens to your data afterward, and fix common problems.

### Official Apps

- [Official Apps](https://docs.dodopayments.com/features/app-marketplace/official-apps.md): Official apps are built and run by Dodo Payments. Install an official app in one click, connect your account, and choose which events to send.

- [Discord App](https://docs.dodopayments.com/features/app-marketplace/discord.md): Install the official Discord app to post payment, refund, dispute, subscription, and payout alerts from Dodo Payments to a Discord channel.
- [Microsoft Teams App](https://docs.dodopayments.com/features/app-marketplace/microsoft-teams.md): Install the official Microsoft Teams app to post payment, refund, dispute, subscription, and payout cards from Dodo Payments to a Teams channel.

#### Analytics

- [PostHog App](https://docs.dodopayments.com/features/app-marketplace/posthog.md): Install the official PostHog app to send payment, subscription, refund, and dispute events from Dodo Payments to PostHog. Connect with your API credentials and choose the events.
- [Mixpanel App](https://docs.dodopayments.com/features/app-marketplace/mixpanel.md): Install the official Mixpanel app to send payment, subscription, refund, and dispute events from Dodo Payments to Mixpanel. Connect with a service account and choose the events.
- [Amplitude App](https://docs.dodopayments.com/features/app-marketplace/amplitude.md): Install the official Amplitude app to send payment, subscription, refund, and dispute events from Dodo Payments to Amplitude. Connect with your API Key and choose the events.
- [Segment App](https://docs.dodopayments.com/features/app-marketplace/segment.md): Install the official Segment app to send payment, subscription, refund, and dispute events from Dodo Payments to Segment. Connect with your Write Key and choose the events.

#### Email and Marketing

- [Resend App](https://docs.dodopayments.com/features/app-marketplace/resend.md): Install the official Resend app to add your Dodo Payments customers to Resend contacts and keep their subscription status. The app sends no email.
- [Loops App](https://docs.dodopayments.com/features/app-marketplace/loops.md): Install the official Loops app to add Dodo Payments customers to Loops as contacts and send payment, refund, and subscription events. The app sends no email.
- [MailerLite App](https://docs.dodopayments.com/features/app-marketplace/mailerlite.md): Install the official MailerLite app to add Dodo Payments customers to MailerLite as subscribers and keep their subscription status. The app sends no email.
- [Customer.io App](https://docs.dodopayments.com/features/app-marketplace/customer-io.md): Install the official Customer.io app to add Dodo Payments customers to Customer.io as people and send payment, subscription, refund, and dispute events. The app sends no message.

#### CRM

- [HubSpot App](https://docs.dodopayments.com/features/app-marketplace/hubspot.md): Install the official HubSpot app to create or update HubSpot contacts for your Dodo Payments customers and add a note for each payment, refund, and dispute.
- [Attio App](https://docs.dodopayments.com/features/app-marketplace/attio.md): Install the official Attio app to create or update Attio people for your Dodo Payments customers and add a note for each payment, refund, and dispute.
- [Close App](https://docs.dodopayments.com/features/app-marketplace/close.md): Install the official Close app to find or create Close contacts for your Dodo Payments customers and add a note to the lead for each payment, refund, and dispute.
- [Pipedrive App](https://docs.dodopayments.com/features/app-marketplace/pipedrive.md): Install the official Pipedrive app to create or update Pipedrive persons for your Dodo Payments customers and add a note for each payment, refund, and dispute.

#### Support

- [Intercom App](https://docs.dodopayments.com/features/app-marketplace/intercom.md): Install the official Intercom app to create or update Intercom users for your Dodo Payments customers and add a note for each payment, refund, and dispute.

- [Freshdesk App](https://docs.dodopayments.com/features/app-marketplace/freshdesk.md): Install the official Freshdesk app to create or update Freshdesk contacts for your Dodo Payments customers and create a ticket for each opened dispute.

### Webhook Connectors

#### Messaging

- [Slack](https://docs.dodopayments.com/integrations/slack.md): Post Dodo Payments events, such as payments, subscription changes, and disputes, to a Slack channel through a Slack incoming webhook.
- [Discord](https://docs.dodopayments.com/integrations/discord.md): Post real-time Dodo Payments notifications, such as payments, subscriptions, and disputes, to your Discord channels through a Discord webhook.
- [Microsoft Teams](https://docs.dodopayments.com/integrations/microsoft-teams.md): Post Dodo Payments events to a Microsoft Teams channel as Adaptive Cards, so your team sees payments, subscription changes, and disputes.

#### Workflow Automation

- [n8n](https://docs.dodopayments.com/integrations/n8n.md): Trigger n8n workflows from Dodo Payments webhook events and connect payments to the apps n8n integrates with, in self-hosted or cloud n8n.
- [Zapier](https://docs.dodopayments.com/integrations/zapier.md): Start Zaps from Dodo Payments events through Webhooks by Zapier, to send payment, subscription, and dispute data to thousands of apps.
- [Windmill](https://docs.dodopayments.com/integrations/windmill.md): Run Windmill scripts and flows when Dodo Payments events occur, to update databases, sync data, or automate business logic in code.
- [Inngest](https://docs.dodopayments.com/integrations/inngest.md): Trigger Inngest serverless functions and background jobs from Dodo Payments payment, subscription, and dispute events.

#### CRM

- [Close CRM](https://docs.dodopayments.com/integrations/close-crm.md): Create Close CRM contacts and opportunities when customers pay or subscribe through Dodo Payments, so your sales team can track leads and revenue in Close.
- [GoHighLevel](https://docs.dodopayments.com/integrations/gohighlevel.md): Integrate Dodo Payments with GoHighLevel (GHL) using no-code payment links, overlay checkout, or inline checkout, and automate fulfillment with webhooks.

#### Customer Support

- [Fernand](https://docs.dodopayments.com/integrations/fernand.md): See Dodo Payments customer, plan, and purchase details on support conversations in Fernand, and route conversations with rules based on whether a contact pays.

#### Email

- [Loops](https://docs.dodopayments.com/integrations/loops.md): Send Dodo Payments events to Loops to trigger payment confirmations, subscription welcome emails, and failed payment notices from your Loops workflows.
- [Resend](https://docs.dodopayments.com/integrations/resend.md): Send transactional emails through Resend when Dodo Payments events occur, such as payment confirmations, subscription welcomes, and payment failure notices.
- [SendGrid](https://docs.dodopayments.com/integrations/sendgrid.md): Send transactional emails through SendGrid's Mail Send API when Dodo Payments events occur, using your SendGrid dynamic templates.
- [AutoSend](https://docs.dodopayments.com/integrations/autosend.md): Send transactional emails through AutoSend's email API when Dodo Payments events occur, such as successful payments, new subscriptions, and failed payments.
- [MailerLite](https://docs.dodopayments.com/integrations/mailerlite.md): Add paying customers to MailerLite subscriber groups and trigger MailerLite automations when Dodo Payments events such as successful payments occur.
- [Keplars](https://docs.dodopayments.com/integrations/keplars.md): Send transactional emails through Keplars when Dodo Payments payment and subscription events occur, with no middleware server.

#### Analytics

- [Segment](https://docs.dodopayments.com/integrations/segment.md): Send Dodo Payments events to Segment as Track and Identify calls, so payments and subscriptions reach your analytics and marketing tools.
- [Customer.io](https://docs.dodopayments.com/integrations/customer-io.md): Send Dodo Payments events to Customer.io to trigger email campaigns and customer journeys, such as welcome emails and payment failure notices.
- [DataFast](https://docs.dodopayments.com/integrations/datafast.md): Attribute Dodo Payments revenue to marketing channels with DataFast analytics, and see which traffic sources bring paying customers.
- [Dub](https://docs.dodopayments.com/integrations/dub.md): Track sale conversion events in Dub when customers complete purchases through Dodo Payments, and attribute revenue to your short links and partners.
- [Rekomi](https://docs.dodopayments.com/integrations/rekomi.md): Run an affiliate program on your Dodo Payments store with Rekomi. One pasted API key connects the two, and Rekomi tracks sales and pays your affiliates.

#### Pricing

- [ParityDeals](https://docs.dodopayments.com/integrations/paritydeals.md): Show location-based discount banners on your website and auto-generate matching discount codes in Dodo Payments with ParityDeals.
- [Evendeals](https://docs.dodopayments.com/integrations/evendeals.md): Sync location-based purchasing power parity discount codes from Evendeals into your Dodo Payments account for one-time and subscription products.

#### Platforms

- [Appwrite](https://docs.dodopayments.com/integrations/appwrite.md): Accept one-time payments and subscriptions in your Appwrite project with two Appwrite Functions templates that store orders and grant subscriber access.
- [PayGlue](https://docs.dodopayments.com/integrations/payglue.md): Sell Ghost memberships and one-time access with Dodo Payments. PayGlue turns each Dodo Payments purchase into a Ghost member and removes access when a subscription ends.
