# Creating payment links

Payment links provide a no-code method for collecting customer payments via chat, email, or phone using secure, Xendit-hosted checkout sessions. Through your dashboard, you can manually generate hosted payment sessions, track active checkouts, and monitor customer activity in real time.

## How to create a payment link

To view the Payment Links tab and create links, ensure your user account has the appropriate [permissions](/v1/docs/users-permissions) assigned by your administrator.

1. Go to the **Payment Links** page
2. Click **Create New**
3. Enter the **payment details**
4. (Optional) Add the **customer information** by adding the Customer ID. If you don’t have the Customer ID, click **Add New Customer**
5. (Optional) Add the description of the payment
6. Configure more customization as preferred
  1. Set custom expiry time on this payment link
  2. Send payment link to customer’s email if there’s customer information added
7. Click **Create Payment Link**
8. Share the payment link with your customer

## Monitoring and Tracking

The main Payment Links interface provides a comprehensive, tabular view of all historical and active payment sessions. You can easily use filters and the search bar to locate specific links or drill down into your payment data.

### Transaction Details

Click on any payment link to view deep-dive transaction insights, including:

- **Overview Timeline:** A chronological audit trail of all events associated with a single payment link (e.g., created, viewed, paid).
- **Transaction Details:** Granular data about the transaction, including payment type, exact creation timestamps, and other metadata.
