Copypasta Keyboard (formerly Dupe Message) is the best and only Copy & Paste app you need! Save your "copypastas" to quickly send them again in the future. Use the Repetition Dial to repeat your copypasta over and over! Use the custom keyboard to send your copypastas in any app. Best of all, use all of these features for free! Features: * Custom Keyboard so you can repeat a message in any app * Save copypastas so you never have to type them again! Use the Repetition dial to repeat them a ton! Compete in copypasta battles and win! * iMessage app * Predefined phrases and emoji to choose from so you can send a huge message with a single tap * A slider to adjust how many times you want the phrase to be duplicated * Text Memes \(^-^)/ ※\(^o^)/※
