Five made-up sites

Each page below is fictional and shows one thing Undirect deals with. Every one of them can only reach a stand-in destination page that does nothing. The same list is on its own page.

Reelhouse, a film site

The first click on the player opens a new window from third-party code.

Bytebarn, a file host

A clear layer covers the page and takes the first press for itself.

Quickpatch, a download page

The Download button sends this same tab to another site.

Saltpan Kitchen, a recipe page

A widget rewrites each link the moment you press it.

Trailpress, a news page that behaves

A sign-in window and an outbound link, both asked for. Undirect leaves them alone.

How to test

Press the Undirect button in Safari to turn it on for this site. Then tap anywhere below.
