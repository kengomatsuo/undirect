Kontakt

Schreiben Sie an kenneth@matsuokengo.com.

Eine Website, die am Schutz vorbeikommt, melden Sie am besten gleich. Die Taste „Problem melden“ in der Erweiterung öffnet ein vorausgefülltes Issue mit allen Angaben.

Häufige Probleme

Undirect erscheint nicht in Safari

Öffnen Sie die App einmal und schalten Sie Undirect dann in den Erweiterungseinstellungen von Safari ein.

Wie schalte ich es für eine Website ein?

Öffnen Sie die Website in Safari und tippen Sie auf die Undirect-Taste. Bis dahin ist der Schutz überall aus. Tippen Sie erneut, um ihn für diese Website auszuschalten.

Eine Website funktioniert nicht mehr, seit ich eine Regel gesetzt habe

Tippen Sie auf die Erweiterungstaste, suchen Sie den Host und wählen Sie die Standardeinstellung. Damit entfällt die Regel.

Ich kann Regeln auf iPhone oder iPad nicht ändern

Die Liste in der App ist dort nur lesbar, weil iOS einer App keinen Weg lässt, Änderungen an die eigene Erweiterung zu senden. Ändern Sie Regeln über die Erweiterungstaste in Safari.

Ein Fenster, das ich wollte, wurde blockiert

Sein Host steht in der Liste. Erlauben Sie ihn auf dieser Website oder überall.
